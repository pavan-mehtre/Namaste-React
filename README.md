# Namaste-React
Learning React from Zero to Hero

# Loading normal HTML + React from CDN not a good idea for production base code

# Follow below steps production build code
- npm init (this will make necessary configuration based on our inputs and gives package.json)
- package.json (Used for configuring NPM packages)
- npm install -D parcel (install parcel)
- npm i react react-dom (install React and ReactDOM)
- Finally run app by -> npx parcel index.html 
- After custom script -> npm run start
